
# B-Tree & LSM-Tree

## Description du projet

Ce projet académique consiste à développer deux
moteurs de stockage de données en C++ :

- B-Tree (Balanced Tree)
- LSM-Tree (Log-Structured Merge-Tree)

Une interface graphique commune permettra à
l'utilisateur de choisir le moteur de stockage
qu'il souhaite utiliser.

## Objectifs

- Comprendre le fonctionnement du B-Tree et du LSM-Tree.
- Implémenter les deux structures en C++.
- Assurer le stockage persistant des données.
- Développer une interface graphique commune.
- Comparer les performances des deux moteurs.

## Fonctionnalités prévues

- Insertion des données.
- Recherche des données.
- Modification des données.
- Suppression des données.
- Affichage des données.
- Stockage sur disque.
- Comparaison des performances.

## Technologies

- C++17
- Qt Widgets
- CMake
- Git et GitHub

## Organisation du projet

- `btree/` : Implémentation du B-Tree.
- `lsmtree/` : Implémentation du LSM-Tree.
- `gui/` : Interface graphique commune.
